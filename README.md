## 💡 프로젝트 배경
- 비급여 치과 진료로 인한 비용 부담을 예방 중심의 치아 관리 서비스로 해소 
- 아동·청소년을 위한 시각적이고 직관적인 양치 교육 
- 양치 시간/방법에 대한 구체적인 피드백과 반복 유도 
- 게임화된 보상으로 재미있는 습관 형성
